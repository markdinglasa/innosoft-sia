# EPIC-TRX-003 — Operational Transaction Management

## Epic Goal
Support real-world POS operations such as hold/recall, cash handling, shift control, and manager-approved actions.

## Features
- FEAT-TRX-006 — Suspended Sales (Hold/Recall)
- FEAT-TRX-007 — Transaction Void & Reversal
- FEAT-TRX-008 — Cash Drawer & Petty Cash
- FEAT-TRX-010 — Manual Override & Sensitive Action Controls
- FEAT-TRX-011 — Shift / Cashier Session Binding

## Business Outcome
- Real cashier usability
- better terminal accountability
- safe correction workflows
- stronger operational control

## Risks
- unauthorized voids
- missing shift ownership
- hidden override abuse
- held order loss

## Implementation Priority
Critical / Phase 3
