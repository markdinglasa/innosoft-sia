# User Journeys: Tabbed Settings Page

## Journey 1: Viewing Settings Categories
As a user, I want to see different settings categories in tabs so I can easily find what I need.
- **Goal**: Render a tabbed interface with Account and Terminal settings.
- **Success Criteria**:
  - Modal/Page renders correctly.
  - Two tabs are visible.

## Journey 2: Switching Tabs
As a user, I want to switch between Account and Terminal settings.
- **Goal**: Change active tab smoothly.
- **Success Criteria**:
  - Clicking a tab updates the active state.
  - Tab content changes correctly.

## Journey 3: Updating Settings
As a user, I want to update terminal settings and see the success notification.
- **Goal**: Form submission triggers a mutation and success message.
- **Success Criteria**:
  - Form values are sent correctly.
  - Toast notification appears.
